# Índice de Especificaciones del Sistema (SDD)
## CHIDAOBA — Judo Olímpico & Brazilian Jiu-Jitsu (Alicante)

Este directorio contiene las especificaciones formales de cada una de las funcionalidades de la plataforma web de Chidaoba, redactadas bajo el enfoque de **Spec-Driven Development (SDD)**.

Cada archivo define:
- `name:` Nombre identificador de la funcionalidad.
- `descripcion:` Detalle técnico y objetivo de negocio/usuario.
- `estado:` Estado actual de implementación.
- `criterios de aceptacion:` Condiciones verificables de aceptación (Given-When-Then y checks funcionales).
